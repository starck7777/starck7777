**Technologies:** Python, Flask, SQLite, HTML, CSS, JavaScript

### Online Examination Seating and Hall Allocation System

An automated system for generating examination seating arrangements and hall allocations using student, subject and room data. The platform reduces manual planning and improves seating accuracy.

**Technologies:** Python, Flask, OpenPyXL, SQLite, HTML, CSS

### Fake News Detection System

A machine-learning application that classifies news articles as authentic or potentially misleading using text preprocessing, TF-IDF feature extraction and supervised classification models.

**Technologies:** Python, Natural Language Processing, Scikit-learn, Pandas, TF-IDF

### GluCare — Diabetes Management Application

A health-management platform for recording glucose levels, meals, activities and calorie information. The system provides progress visualisation and structured health records.

**Technologies:** Python, Flask, SQLite, Chart.js, HTML, CSS, JavaScript

### RoadSense AI — Road Damage Detection System

An AI-powered system designed to detect road cracks and potholes from images, estimate severity and associate identified damage with location information for maintenance tracking.

**Technologies:** Python, Computer Vision, Convolutional Neural Networks, Machine Learning
